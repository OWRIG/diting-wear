# 谛听外壳 v1 设计说明

第一版用来验证装配：板子能不能装进去、USB 能不能插、孔位对不对、卡扣和背夹好不好用。PLA 打样，确认后再用 PETG 打正式版。

## 1. 被装的东西（用户 2026-11-06 实测，单位 mm）

XIAO nRF54L15 Sense，背面贴一块 402020 电池，外面包了一层聚酰亚胺胶带。

| 项目 | 实测 |
|---|---|
| 宽（左右） | 19.6 |
| 长（不含 USB，从 PCB 的 USB 侧边缘量到电池、保护板和导线的另一头） | 21.5 |
| 长（含 USB） | 23.5，所以 USB-C 伸出 PCB 边缘 2.0 |
| 厚（屏蔽罩到电池背面） | 10.6 |
| 厚（USB-C 处，USB 顶面到电池背面） | 11.6 |

推算值（**不是实测**，第一版打完要靠实物验证）：USB-C 插座是 8.94 × 3.26 的标准尺寸，所以从电池背面量起，PCB 正面约 8.34、USB 中心约 9.97，麦克风顶约 9.3。

板载元件的位置来自 Seeed 官方 pinout 图（`XIAO_nRF54L15_Sense_front_pinout.png`）。PCB 名义 21 × 17.8。下表以 PCB 中线为 x=0，到 PCB 的 USB 侧边缘的距离记为 d：

| 元件 | x | d | 外壳处理 |
|---|---|---|---|
| 麦克风（两个按键中间的银色小方块） | 0 | 16.1 | 进声孔 + 导声管 |
| 复位键 R | −4.7 | 16.1 | 顶针孔 |
| 用户键 B | +4.5 | 16.1 | 顶针孔 |
| 充电灯（红，USB 左边） | −6.3 | 0.9 | 内侧挖薄做透光窗 |
| 用户灯（绿，USB 右边） | +6.3 | 0.9 | 内侧挖薄做透光窗 |
| 板载陶瓷天线 | +3.2 | 19.5 | 附近不放金属 |

## 2. 坐标系（装配状态）

从正面看外壳：**x 向右，y 向上（朝 USB），z 从正面朝外**（右手系）。正面外表面在 z=0，壳体在 z<0 一侧。腔体底边（远离 USB 的一头）在 y=0，左右以 x=0 为中线。

## 3. 参数

```
CAV_W = 20.2      # 腔体宽 = 19.6 + 0.6
CAV_L = 22.0      # 腔体长 = 21.5 + 0.5，y ∈ [0, 22.0]
CAV_H = 12.0      # 电子件空间 = 11.6 + 0.4
CAV_R = 0.5       # 腔体竖边圆角（电池是方角，不能大）
WALL_SIDE = 1.2   # 左右壁、底端（-y）壁
WALL_USB = 1.8    # USB 端（+y）壁，USB 插口端面比外表面缩进约 0.05
FRONT = 1.2       # 正面壁厚
LID_T = 2.0       # 后盖厚度
OUT_R = 2.0       # 外形竖边圆角
```

几个推导出的数：
- 外形：x ∈ [−11.3, 11.3]（22.6），y ∈ [−1.2, 23.8]（25.0），z ∈ [−15.2, 0]（15.2）
- 腔体：x ∈ [−10.1, 10.1]，y ∈ [0, 22.0]，z ∈ [−15.2, −1.2]；电子件在 z ∈ [−13.2, −1.2]，后盖嵌在 z ∈ [−15.2, −13.2]
- PCB 的 USB 侧边缘在 y = 21.75（留 0.25 间隙），元件的 y = 21.75 − d
- 板子上一个"离电池背面高 h"的点，z = −13.2 + h

## 4. 零件

### A. 前壳 `case-front`（一体杯形，正面朝下打印）

1. **外形**：圆角矩形柱，正面外边倒角 0.5（顺便抵消象脚），后口外边倒角 0.4。
2. **腔体**：上面那个尺寸的圆角矩形腔，从 z=−1.2 一直通到 z=−15.2 开口。
3. **USB 口**（+y 壁）：x ∈ [−4.7, 4.7]，z ∈ [−5.06, −1.4]，贯穿 +y 壁。**再从 z=−5.06 往后一直开到后口 z=−15.2**，做成朝后开口的 U 形槽，板子才能从后面直接放进去。U 形槽剩下的部分由后盖的舌片补上。
4. **麦克风**：在 (0, 5.65) 打 Ø1.5 通孔穿过正面壁；内侧做一根导声管，外径 2.8、内径 1.5，从 z=−1.2 伸到 z=−3.0（名义上离麦克风约 0.9）。
5. **顶针孔**：在 (−4.7, 5.65) 和 (+4.5, 5.65) 各打一个 Ø1.6 通孔。
6. **灯窗**：在 (±6.3, 20.85) 从内侧挖 Ø2.6 的盲孔，从 z=−1.2 挖到 z=−0.36，正面只留 0.36 厚的壳壁透光。
7. **卡扣槽**：左右两侧内壁（x=±10.1）各一条水平槽，截面是三角形，深 0.45、高 1.2，以 z=−14.2 为中心，沿 y 长 13，以 y=11 为中心。
8. **撬口**：−y 端后口处开缺口，x ∈ [−2, 2]，穿透 −y 壁，z ∈ [−15.2, −14.4]，方便用指甲撬开后盖。
9. **挂绳耳**：从 −y 端伸出，z ∈ [−3.0, 0]，和正面平齐。取 x 中心宽 7 的矩形（y 从 −0.5 到 −5.0）和圆心 (0, −5.0)、半径 3.5 的圆，两者做凸包。在 (0, −5.0) 沿 z 打 Ø2.6 通孔，挂 1–2mm 的绳子。

### B. 后盖 `case-back`（外表面朝下打印）

1. **盖板**：x ∈ [−10.0, 10.0]，y ∈ [0.1, 21.9]（每边比腔体小 0.1），圆角 0.4，z ∈ [−15.2, −13.2]。外边倒角 0.3。
2. **USB 舌片**：x ∈ [−4.6, 4.6]，y ∈ [22.0, 23.8]，z ∈ [−15.2, −5.16]，和盖板连成一体，补上前壳的 U 形槽（顶面离 USB 口下沿 0.1）。
3. **卡扣凸棱**：盖板左右两边（x=±10.0）各一条三角凸棱，高出 0.35，高 1.0，以 z=−14.2 为中心，沿 y 长 12，以 y=11 为中心。
4. **背夹燕尾槽**：开在外表面 z=−15.2，深 1.0（到 z=−14.2）。槽口宽 6.0，槽底宽 7.6（口窄底宽）。沿 y 方向从 y=2.0（封死，做背夹的挡块）一直开到 y=23.8，从 USB 端开口出去（会穿过舌片底部）。
   - 戴的时候 −y 端（挂绳耳那头）朝上。机身的重量会把背夹往挡块上压，背夹不会自己滑出来。

### C. 背夹 `clip`（侧放打印，让层纹沿着弹片弯曲的方向）

整个背夹在 x ∈ [−6, 6]（宽 12）内，是 y-z 平面上的截面沿 x 拉伸出来的，伸在后盖外侧（z < −15.2）：

- **底板**：y ∈ [1.0, 23.0]，z ∈ [−16.6, −15.2]，厚 1.4
- **弹片**：y ∈ [2.8, 20.0]，z ∈ [−18.8, −17.4]，厚 1.4，和底板之间间隙 0.8
- **U 形弯**（在 −y 端）：圆心 (y=2.8, z=−17.0) 的半圆环，内半径 0.4、外半径 1.8，开口朝 +y，把底板和弹片连起来
- **夹紧凸点**：弹片内侧 y≈17 处一条横向凸棱，朝底板凸出 0.6（间隙剩 0.2），夹住衣服
- **导入翘边**：弹片末端 y ∈ [20.0, 22.5] 向外（−z）翘出 1.0，衣服好塞进去
- **燕尾舌**：从底板 z=−15.2 往 +z 伸 0.9，y ∈ [2.1, 23.0]。根部（z=−15.2）宽 5.7，顶端（z=−14.3）宽 7.3，跟燕尾槽每边留 0.15 间隙。从 USB 端推进去，推到 y=2.0 的挡块为止

## 5. 打印方向（坐标变换必须是精确的轴置换，不能用三角函数旋转）

| 零件 | 变换（装配坐标 → 打印坐标） | 落在打印板上的面 |
|---|---|---|
| case-front | (x, y, z) → (−x, y, −z) | 正面朝下，挂绳耳也贴着打印板 |
| case-back | (x, y, z) → (x, y, z + 15.2) | 外表面朝下，燕尾槽开口在底面 |
| clip | (x, y, z) → (z, y, −x)，再平移 | 侧面朝下，U 形截面平放在打印板上 |

三个零件都不需要支撑。燕尾槽顶部有一段 7.6mm 的短桥接，其余悬空都在 45° 以内。

## 6. 切片（K3，单色 PLA）

参考 `~/Documents/ChatGPT/3d printer/.agents/skills/3d-print-prep/` 的流程和陷阱，模板用 `~/Documents/ChatGPT/3d printer/Claude/clawd-desk-pet/v10-peg-fit/plates/41-replacement-pegs-K3-v10.3mf`（Creality K3、0.4 喷嘴、Hyper PLA、纹理 PEI、单色、无擦料塔）。

- 层高 0.16，3 道墙，100% 填充（零件都很小），**不加支撑，不加 brim**（`brim_type=no_brim`）
- 三个零件放在同一盘，彼此间隔 ≥ 5mm
- 改过的工艺键要写进 `different_settings_to_system`，否则载入时会被系统默认值顶掉
- 用本地 CLI 切片：`CrealityPrint --cli --slice 1 --need-gcode-file --outputdir <dir> <project.3mf>`
- **只在本地切片和导出，不发送到打印机，也不操作打印机**

## 7. 交付物（放在 `enclosure/v1/`）

- `build.py`：Blender 后台模式运行（`Blender -b --factory-startup --python build.py`），参数都集中在文件开头，可以重复运行
- `parts/case-front.stl`、`parts/case-back.stl`、`parts/clip.stl`：按打印方向放好，单位 mm
- `previews/`：装配图、爆炸图、打印排布图，至少各一张（Workbench 渲染就够）
- `geometry-report.json`：每个零件的包围盒、体积、非流形边数（必须为 0）、连通体数（各为 1），以及装配干涉检查（装配状态下三件两两之间的相交体积应约为 0）
- `diting-case-v1-K3.3mf`、`diting-case-v1-K3.gcode`、`slicing-report.json`（时间、耗材、层数）、`PRINTING.txt`
